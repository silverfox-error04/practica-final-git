# Aprendizajes
entre los comandos que mas se usan en la creacion de repositorios para HitHub estan:
"git status" un comando usado para verificar el estado de la rama y la rama en la que te encuentras.
"git switch" que sirve para cambiar entre ramas.
"git add" que finciona para guardar cambios realizados en la rama.
"git commit" que tiene la funcion de subir los cambios realizados a GitHub.
"git clone" que funciona para clonar un repositorio desde GitHub hacia el ordenador.
